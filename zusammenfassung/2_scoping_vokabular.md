# Vokabular: Scoping-Workshop

## Kernbegriffe

| Begriff | Definition |
|---|---|
| **Scoping-Workshop** | Erster Workshop im Vorgehensmodell; klärt Projektauftrag, Metriken und Annahmen |
| **Stakeholder** | Anspruchsgruppen, die von einer Lösung direkt oder indirekt betroffen sind |
| **Problem Statement** | Beschreibt die zu bearbeitende Fragestellung: welches Problem, wer ist betroffen, welche Randbedingungen |
| **Proto-** (Präfix) | Kennzeichnet vorläufige, nicht validierte Artefakte (von lat. „erstmalig", „frühest") |
| **Metrik** | Bildet eine Produkteigenschaft auf ein qualitatives oder quantitatives Gütemaß ab |
| **Operationalisierung** | Konkrete Festlegung, wie eine Metrik gemessen wird |
| **Randbedingung** | Erfolgskritische Einschränkung oder Vorgabe, die bei der Lösungsfindung eingehalten werden muss |
| **Risiko** | Mögliches Problem mit Eintretenswahrscheinlichkeit und Auswirkung; noch nicht sicher eingetreten |
| **Projektrisiko** | Risiko, das sich während der Projektlaufzeit auswirkt |
| **Produktrisiko** | Risiko, das sich erst nach dem Release eines Produkts manifestieren kann |
| **Annahme** | Vermutung, deren Wahrheitsgehalt noch nicht gesichert ist |
| **Kritische Annahme** | Annahme mit hoher Unsicherheit und hohem Einfluss auf den Projekterfolg |

## Personas

| Begriff | Definition |
|---|---|
| **Proto-Persona** | Hypothetischer archetypischer User, der eine Nutzergruppe repräsentiert; basiert auf Annahmen, nicht auf Forschung |
| **Persona** | Empirisch validiertes Modell eines archetypischen Users; basiert auf Nutzerforschung |
| **Archetypischer User** | Stellvertretende fiktive Person für eine Gruppe mit ähnlichen Anforderungen |

## Journeys

| Begriff | Definition |
|---|---|
| **Proto-Journey** | Hypothetischer Ablauf zur Erreichung eines Ziels einer Persona; beschreibt den Ist-Zustand, nicht die Lösung |
| **Journey Map** | Visualisierung eines Prozessablaufs mit Schritten, Problemen und Chancen im zeitlichen Verlauf |

## Annahmen-Map

| Begriff | Definition |
|---|---|
| **Annahmen-Map** | Koordinatensystem zur Priorisierung von Annahmen nach Unsicherheit (x-Achse) und Einfluss (y-Achse) |
| **Unsicherheit** | Grad des Zweifels an der Korrektheit einer Annahme |
| **Einfluss** | Erwarteter Schaden, wenn sich eine Annahme als falsch erweist |

## Workshop-Prinzipien

| Begriff | Definition |
|---|---|
| **Timeboxing** | Strikte zeitliche Begrenzung von Workshop-Aktivitäten |
| **Einsam und gemeinsam** | Wechselspiel zwischen Einzelarbeit und gemeinsamen Aktivitäten |
| **Ergebnisorientierte Gestaltung** | Workshop-Leitung bereitet Struktur der Ergebnisse vor Beginn vor |

## Workshop-Phasen

| Begriff | Definition |
|---|---|
| **Präsentation** | Vorstellung vorbereiteter Ergebnisse an die Gruppe |
| **Fragerunde** | Explizite Phase nach der Präsentation zum Klären von Unklarheiten |
| **Feedback** | Strukturierte Rückmeldung mit Urteil + Begründung; Ich-Botschaften |
| **Bewerten** | Trennung der Bewertung von Präsentation/Feedback; z.B. durch Punkte oder Diagramme |
| **Sammeln** | Gezieltes Erkunden des Lösungsraums in der Breite |
| **Gruppieren** | Zusammenfassen bedeutungsähnlicher Aspekte; z.B. Affinity Diagramming |
| **Ausarbeiten** | Konkretisierung durch Skizzen, Szenarien oder Prototypen |
| **Proof of Concept** | Technischer Prototyp zur Überprüfung und Bewertung eines technischen Risikos |
