# Vokabular – Kapitel 6: Prototyping

---

## Prototypen & Fidelity

| Begriff | Definition |
|--------|-----------|
| **Prototyp** | Artefakt zur Repräsentation von Systemzuständen unter bestimmten Bedingungen; dient der Validierung von Konzeptannahmen |
| **Fidelity-Grad** | Ausarbeitungsgrad eines Prototyps; unterschieden in inhaltlich, visuell und interaktional |
| **Inhaltlicher Fidelity-Grad** | Grad, zu dem echte Inhalte statt Platzhalter im Prototyp eingesetzt werden |
| **Visueller Fidelity-Grad** | Grad der visuellen Ausarbeitung (Farben, Typografie, Assets); Low: Sketches, High: finales Design |
| **Interaktionaler Fidelity-Grad** | Grad, zu dem Interaktionsverhalten (inkl. Animationen, Übergänge) im Prototyp erlebbar ist |
| **Low-Fidelity-Prototyp** | Einfacher, schnell erstellter Prototyp; fördert offenes Feedback, da nichts "in Stein gemeißelt" wirkt |
| **High-Fidelity-Prototyp** | Ausgereifter, detaillierter Prototyp; aufwendig, aber nahe am finalen Produkt |
| **Papierprototyp** | Einfachste Form eines Prototyps; gezeichnet auf Papier; signalisiert Offenheit für Änderungen |
| **Funktionaler Prototyp** | Implementiert umfassendere Funktionsbereiche; für Usability-Tests und Machbarkeitsprüfung |
| **Vertical Slice** | Prototyp, der genau eine Funktion vollständig implementiert; zur Prüfung technischer Machbarkeit |

## Validierungsplanung

| Begriff | Definition |
|--------|-----------|
| **Annahme** | Hypothetische Aussage über Nutzerbedürfnisse oder Produkteigenschaften, die im Konzept enthalten ist |
| **Annahmen-Map** | Strukturierte Darstellung der Konzeptannahmen mit Dimensionen: Annahme, Unsicherheit, Einfluss |
| **Unsicherheit** | Wie unsicher eine Annahme ist — wichtige Dimension für die Priorisierung von Validierungen |
| **Einfluss** | Wie groß der negative Effekt wäre, wenn eine Annahme sich als falsch herausstellt |
| **Validierungsplan** | Vollständige Annahmen-Map inkl. Methode, Prototyp, Stichprobe, Erfolgskriterien, Aufwand |
| **Erfolgskriterien** | Vorher festgelegte Bedingungen, unter denen eine Validierung als erfolgreich gilt |

## Validierungsmethoden

| Begriff | Definition |
|--------|-----------|
| **Konzept-Walkthrough** | Präsentation eines Szenarios (+ Screens/Storyboard) in Einzel- oder Gruppengesrächen; Ziel: erste Eindrücke und Kontraindikatoren |
| **Storyboard** | Comic-ähnliche Darstellung, die den Kontext und die Lösung anschaulich visualisiert |
| **Fokusgruppe** | Gruppengespräch mit mehreren Teilnehmenden zur Diskussion eines Konzepts |
| **Fake-Door-Experiment** | Ankündigung einer noch nicht existierenden Funktion; Messung des Interesses anhand von Klicks |
| **Anforderungs-Walkthrough** | Walkthrough zur Prüfung, ob alle notwendigen Funktionalitäten vorhanden sind |
| **Concierge-Experiment** | Manuelle Bereitstellung einer Dienstleistung statt automatisierter Umsetzung; frühe Validierung des Nutzens |
| **Wizard-of-Oz** | Ein Mensch simuliert das System; Testpersonen glauben, ein echtes System zu bedienen |
| **Usability-Walkthrough** | Informeller Test mit 3–4 Personen; frühe Hinweise auf Usability-Barrieren |
| **Usability-Test im Labor** | Detaillierter, formaler Test mit Testpersonen; aufwendiger als Walkthrough |
| **A/B-Test** | Systematischer Vergleich zweier Designvarianten anhand vordefinierter Metriken; bei Plattformen mit vielen Usern |
| **Vergleichender Usability-Test** | Zwei Prototypen, gleiche Aufgaben; Vergleich von Bearbeitungszeit, Fehlern, Zufriedenheit |
| **Fragebogen (Benchmarking)** | Messung und Vergleich mit Durchschnittswerten, Mitbewerbern oder früheren Releases |

## GOMS-Modell

| Begriff | Definition |
|--------|-----------|
| **GOMS** | Goals, Operators, Methods and Selection Rules — analytische Methode zur Berechnung von Aufgabenbearbeitungszeiten |
| **GOMS-Keystroke-Modell** | Variante von GOMS; berechnet Gesamtdauer einer Aufgabe als Summe der Zeiten für Einzelaktionen |
| **Tastendruck** | GOMS-Aktion: 0,2 Sekunden |
| **Selektion** | GOMS-Aktion (Mausklick auf Position): 1,1 Sekunden |
| **Wechsel** | GOMS-Aktion (Wechsel zwischen Tastatur und Maus): 0,4 Sekunden |
| **Mentale Vorbereitung** | GOMS-Aktion (Nachdenken vor einem Schritt): 1,35 Sekunden |
| **Wartezeit** | GOMS-Aktion (Warten auf System-Antwort): systemabhängig |
| **Fitts'sches Gesetz** | Gesetz zur präzisen Berechnung von Selektionszeiten in Abhängigkeit von Zielgröße und Distanz |

## Testaufgaben

| Begriff | Definition |
|--------|-----------|
| **Testszenario** | Beschreibung einer realistischen Situation, in der Testpersonen eine Aufgabe durchführen sollen |
| **Testaufgabe (Task)** | Konkrete Handlungsaufforderung innerhalb eines Testszenarios |
| **Warm-up-Aufgabe** | Erste, einfachere Aufgabe zum schnellen Eindenken in die Testsituation |
| **Stichprobe** | Auswahl an Testpersonen für eine Validierungsstudie |
| **Erfolgskriterium** | Vordefinierte Bedingung, wann eine Testperson eine Aufgabe als erfüllt gilt |
